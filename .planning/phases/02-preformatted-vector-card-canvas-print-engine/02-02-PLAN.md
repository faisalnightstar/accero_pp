<task id="1" name="Define Card TypeScript Data Interfaces">
Create `src/types/cards.ts` with strict types:
- `PanCardData`:
  - `panNumber`: string (e.g. `ABCDE1234F`)
  - `fullName`: string
  - `fatherName`: string
  - `dateOfBirth`: string (DD/MM/YYYY)
  - `photoUrl`?: string
  - `signatureUrl`?: string
  - `qrData`?: string
- `VoterCardData`:
  - `epicNumber`: string (e.g. `AXH0801639`)
  - `electorName`: string (English)
  - `electorNameRegional`?: string (Devanagari/Hindi)
  - `relationType`: 'FATHER' | 'HUSBAND' | 'OTHER'
  - `relationName`: string
  - `relationNameRegional`?: string
  - `gender`: 'Male' | 'Female' | 'Other'
  - `age`?: string | number
  - `dateOfBirth`?: string
  - `assemblyConstituency`: string
  - `assemblyConstituencyRegional`?: string
  - `partNumberAndName`: string
  - `partNumberAndNameRegional`?: string
  - `fullAddress`: string
  - `fullAddressRegional`?: string
  - `photoUrl`?: string
  - `signatureUrl`?: string
  - `issueDate`?: string
</task>

- Front side:
  - Header: "INCOME TAX DEPARTMENT / भारत सरकार GOVT. OF INDIA".
  - Ashoka Lions emblem at top-left.
  - Photo frame (left or right) with placeholder silhouette fallback.
  - Cardholder details: Full Name, Father's Name, Date of Birth.
  - Large Permanent Account Number formatted with tracking.
  - Signature strip at bottom.
  - Dynamic QR code embedded at bottom right / center containing PAN payload.
- Back side:
  - Return instructions, Income Tax PAN contact, customer care helpline, barcode strip.
</task>

<task id="4" name="Build VoterCardCanvas (Front & Back)">
Create `src/components/cards/VoterCardCanvas.tsx`:

- Front side:
  - Header: "ELECTION COMMISSION OF INDIA / भारत निर्वाचन आयोग".
  - Ashoka Lions & security hologram band.
  - Large EPIC Number (e.g. `AXH0801639`) prominently styled.
  - Bilingual fields: Name in Devanagari + English, Father's/Husband's Name in Devanagari + English.

  - Assembly Constituency No & Name (English + Regional).
