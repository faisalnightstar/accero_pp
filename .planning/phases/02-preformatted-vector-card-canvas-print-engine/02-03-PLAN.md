<task id="5" name="Implement 1-Click High-DPI PDF & PNG Export Utility">
Create `src/lib/cardExport.ts`:
- `exportCardAsPdf(frontElement: HTMLElement, backElement: HTMLElement, filename: string)`:
  - Uses `html2canvas` with `scale: 3` (300+ DPI), `useCORS: true`, `backgroundColor: null`.
  - Instantiates `jsPDF({ orientation: 'landscape', unit: 'mm', format: [85.60, 53.98] })`.
  - Inserts Front on Page 1, adds page, inserts Back on Page 2.
  - Saves file as `${filename}.pdf`.
- `exportCardAsPng(element: HTMLElement, filename: string)`:
  - Captures element via `html2canvas` and triggers browser download of `${filename}.png`.
</task>
