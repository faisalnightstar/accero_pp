<tasks>

<task id="1" name="Install QR & Canvas Dependencies">
Install `qrcode` and `@types/qrcode` as project dependencies. Also install `jspdf` and `html2canvas` to prepare for high-DPI export.

```bash
npm install qrcode jspdf html2canvas
npm install --save-dev @types/qrcode
```
Verify `package.json` reflects the installed packages.
</task>

<task id="2" name="Configure CR80 Print Stylesheets in globals.css">
Update `src/app/globals.css` with exact `@page` rules and print utility classes:
- `@page { size: 85.6mm 53.98mm; margin: 0; }` for single-card PVC tray printing.
- Print media adjustments: `-webkit-print-color-adjust: exact`, `print-color-adjust: exact`, `overflow: hidden`.
- Hide all `.no-print` navigational and chrome elements during printing.
- Page break control: `.print-break-after { page-break-after: always; }`.
- Provide an alternate `@media print` class `.print-a4-sheet` for dual-side A4 printing with cutting marks.
</task>

<task id="3" name="Build CardQrCode & Cr80CardContainer Components">
1. Create `src/components/cards/CardQrCode.tsx`:
   - Accepts `value: string`, `size?: number`, `className?: string`, `level?: 'L' | 'M' | 'Q' | 'H'`.
   - Generates SVG or high-resolution canvas data URL using `qrcode.toDataURL()` or `qrcode.toString()`.
   - Graceful fallback with placeholder if value is empty.
2. Create `src/components/cards/Cr80CardContainer.tsx`:
   - Dimensions: fixed physical CSS aspect ratio matching 85.60 mm width by 53.98 mm height (approx 324px × 204px at 1x screen scale or 648px × 408px at 2x).
   - Props: `front: React.ReactNode`, `back: React.ReactNode`, `activeSide?: 'front' | 'back' | 'both'`, `zoom?: number`, `showGuides?: boolean`.
   - Supports 3D flip card toggle or side-by-side mode.
   - Exact border radius of 3.18mm (`rounded-[3.18mm]` or `rounded-[12px]`).
</task>

<task id="4" name="Build PrintControls & Showcase Page">
1. Create `src/components/cards/PrintControls.tsx`:
   - Buttons: "Print PVC Card (Tray)", "Print A4 Sheet", "Zoom 100% / 150% / 200%", "Flip Card (Front / Back)".
   - Executes `window.print()` with target print configuration.
2. Create `src/app/cards/page.tsx`:
   - Interactive preview dashboard allowing operators to view the base CR80 canvas container, test zoom controls, toggle flip state, and test physical browser print preview (`window.print()`).
</task>

</tasks>
