<tasks>

<task id="1" name="Build useCardStudio Controlled State Hook">
Create `src/hooks/useCardStudio.ts`:
- Manages `docType: DocumentType` ('pan' | 'aadhaar' | 'voter' | 'dl' | 'rc').
- Manages `data: any` with default mock fixtures for all 5 document types.
- Provides `updateField(key: string, value: any)` for seamless nested and flat updates.
- Provides `resetToOriginal()` to restore initial API payload or blank template.
- Provides `switchDocType(newType: DocumentType)` with default template seeding.
</task>

<task id="2" name="Create StudioLayout Dual-Pane Component">
Create `src/components/studio/StudioLayout.tsx`:
- Accepts `form: React.ReactNode`, `preview: React.ReactNode`, `headerControls: React.ReactNode`.
- Desktop (`lg:`): Left column (45%-50% width) for scrollable form fields; Right column (50%-55% width) sticky viewport (`sticky top-20`) for the live card preview.
- Mobile/Tablet (`<lg`): Stacked layout with sticky preview bar and collapsible controls.
</task>

<task id="3" name="Build Dynamic CardForm Component">
Create `src/components/studio/CardForm.tsx`:
- Dynamically renders input sections based on `docType`:
  - **PAN**: PAN Number, Full Name, Father's Name, Date of Birth.
  - **Aadhaar**: Aadhaar Number, Name (English + Regional), DOB, Gender, Care of (C/O), Address (English + Regional).
  - **Voter**: EPIC Number, Elector Name (English + Regional), Relation Name (English + Regional), Gender, Age/DOB, Assembly Constituency (English + Regional), Part No & Name (English + Regional), Full Address (English + Regional).
  - **DL**: DL Number, Holder Name, Father/Husband Name, DOB, Blood Group, Issue Date, Validity NT/TR, Address, Vehicle Classes.
  - **RC**: Registration Number, Reg Date, Chassis Number, Engine Number, Owner Name, S/W/D of, Vehicle Class, Maker/Model, Fuel Type, Address, Financier.
- Connects every input to `onFieldChange(key, value)`.
</task>

<task id="4" name="Assemble Studio Route at src/app/studio/page.tsx">
Create `src/app/studio/page.tsx`:
- Integrates `useCardStudio`, `StudioLayout`, `CardForm`, `PrintControls`, and `Cr80CardContainer`.
- Renders corresponding vector canvas (`PanCardCanvas`, `AadhaarCardCanvas`, `VoterCardCanvas`, `DlCardCanvas`, `RcCardCanvas`) based on selected `docType`.
- Supports live typing with 0ms lag, zoom adjustments, flip view, and PVC print preview.
</task>
