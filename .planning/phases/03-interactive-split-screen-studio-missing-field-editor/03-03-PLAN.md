<tasks>

<task id="1" name="Build AssetDropzone Component">
Create `src/components/studio/AssetDropzone.tsx`:
- Accepts `label: string`, `value?: string`, `onChange: (base64: string) => void`, `onClear: () => void`, `aspectRatio?: 'photo' | 'signature'`.
- Drag-and-drop zone supporting drag over, file selection via file dialog, and clipboard paste.
- Converts image to base64 data URL using `FileReader.readAsDataURL()`.
- Validates file type (`image/jpeg`, `image/png`, `image/webp`) and max file size (5MB).
- Shows live image thumbnail preview, file size badge, and "Change" / "Remove" buttons.
</task>

<task id="2" name="Integrate AssetDropzone into CardForm">
Update `src/components/studio/CardForm.tsx`:
- Add photo dropzone to PAN, Aadhaar, Voter, DL.
- Add signature dropzone to PAN and DL.
- Connect dropzone output directly to `photoUrl` and `signatureUrl` fields.
</task>

<task id="3" name="Build MongoDB Documents API Route Handlers">
1. Create `src/app/api/documents/route.ts`:
   - `POST`: Authenticates JWT session, validates payload with Zod schema (`docType`, `docNumber`, `data`, `status`), saves new or updates existing `DocumentRecord` in MongoDB, returns saved document ID and timestamps.
   - `GET`: Authenticates session, queries user's `DocumentRecord` entries, supports optional `?docType=` filter, returns paginated list sorted by `createdAt: -1`.
2. Create `src/app/api/documents/[id]/route.ts`:
   - `GET`: Authenticates session, fetches document by `id` ensuring `userId` matches, returns record for studio re-hydration.
   - `DELETE`: Allows user to archive or remove saved document record.
</task>

<task id="4" name="Implement Manual Entry & Save Flow in Studio">
Update `src/app/studio/page.tsx`:
- Add "New Blank Document" button to switch into manual entry mode with cleared inputs.
- Add "Save Document" button in studio action bar:
  - Sends `POST /api/documents` with current card payload and completion score.
  - Displays saving spinner and success confirmation modal/banner with options: "Stay in Studio", "Go to Dashboard", or "Print Now".
- Handle query parameter `?id=<docId>` to load existing document from `/api/documents/[id]` for seamless editing.
</task>

<task id="5" name="Sync Saved Documents with Operator Dashboard">
Update `src/app/dashboard/page.tsx`:
- Fetch user's saved document records dynamically from `/api/documents`.
- Display recent cards list with Document Type badge, ID number, status (`completed` / `draft`), date, and quick actions:
  - "Open in Studio" (links to `/studio?id=<docId>`)
  - "Print Card" (links to `/cards?id=<docId>` or triggers print)
</task>

</tasks>
