<tasks>

<task id="1" name="Build Declarative Missing Fields Engine">
Create `src/lib/missingFields.ts`:
- Define `DocumentFieldRule` with `key`, `label`, `required`, `section`, `placeholder`.
- Implement validation rule sets for all 5 document types:
  - `panRules`: PAN number, Full Name, Father's Name, DOB, Photo, Signature.
  - `aadhaarRules`: Aadhaar number, Name, Name (Regional), DOB, Gender, Care of, Address, Address (Regional), Photo.
  - `voterRules`: EPIC number, Elector Name, Name (Regional), Relation Name, Gender, AC, Part No, Address, Photo.
  - `dlRules`: DL number, Holder Name, Father/Husband Name, DOB, Blood Group, Address, Issue Date, Validity NT, Vehicle Classes, Photo, Signature.
  - `rcRules`: Reg Number, Reg Date, Chassis Number, Engine Number, Owner Name, Vehicle Class, Maker/Model, Fuel Type, Address.
- Implement `analyzeDocumentCompleteness(docType, data)` returning:
  - `totalRequired`: number
  - `filledCount`: number
  - `missingKeys`: string[]
  - `missingFields`: DocumentFieldRule[]
  - `completionScore`: number (0-100)
  - `isPrintReady`: boolean
</task>

<task id="2" name="Build MissingFieldBanner Component">
Create `src/components/studio/MissingFieldBanner.tsx`:
- Progress bar displaying `completionScore`% (Green if 100%, Amber if <100%, Red if <50%).
- Status text: e.g. "All Required Fields Complete - Ready to Print" vs "⚠️ 2 Incomplete Fields Found".
- "Fix Next Missing Field" button: scrolls to and focuses the first input field in `missingKeys`.
- Toggle button: "Show Canvas Guides" (turns on/off dashed warning boxes on the card preview).
</task>

<task id="3" name="Integrate Amber Badges into CardForm">
Update `src/components/studio/CardForm.tsx`:
- Accept `missingKeys: string[]`.
- For any field whose key is in `missingKeys`:
  - Display amber pill badge next to label: `⚠️ Missing from API`.
  - Apply highlighted border style: `border-amber-400 bg-amber-50/20 focus:border-amber-500 focus:ring-amber-200`.
  - Provide an ID matching the field key so `MissingFieldBanner` can jump/focus directly.
</task>

<task id="4" name="Connect Engine to Studio Page Route">
Update `src/app/studio/page.tsx`:
- Compute `completeness` in real-time on every keystroke.
- Mount `MissingFieldBanner` at the top of the form editor.
- Pass `missingKeys` to both `CardForm` and the card preview canvases for visual feedback.
</task>

</tasks>
