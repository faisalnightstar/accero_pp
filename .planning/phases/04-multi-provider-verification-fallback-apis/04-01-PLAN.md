<action>
1. Create `src/lib/verify/orchestrator.ts`:
   - `executeProviderCascade(docType: DocumentType, queryId: string, providers: ProviderAdapter[]): Promise<VerificationResult>`:
     - Loops through `providers` in priority order.
     - If provider succeeds with non-empty data, returns immediately with `success: true`.
     - Catches errors and timeouts, logging non-sensitive audit info, and seamlessly cascades to the next provider.
     - If all providers fail or return empty data, returns a graceful fallback `VerificationResult` with `success: false` and `isPartial: false`.
2. Create `src/actions/verify.ts`:
   - Mark with `'use server'`.
   - `verifyDocument(docType: DocumentType, idNumber: string): Promise<VerificationResult>`:
     - Validates and sanitizes input (`idNumber.trim().toUpperCase()`).
     - Resolves provider chain based on `docType`:
       - `voter`: `[FastNexoraProvider, NeoApiProvider, MockProvider]`
       - `pan`: `[NeoApiProvider, MockProvider]`
     - Calls `executeProviderCascade(docType, sanitizedId, providers)`.
</action>
