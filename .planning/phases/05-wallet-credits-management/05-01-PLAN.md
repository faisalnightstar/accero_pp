<task type="auto">
  <name>Task 3: Server Actions for Wallet Accounting</name>
  <files>src/actions/wallet.ts</files>
  <action>
    Create `src/actions/wallet.ts` with `'use server'`:
    - `getWalletBalance()`:
      - Retrieves current session user.
      - Finds user's `Wallet` (auto-creates if missing with 0 balance).
      - Returns `{ success: true, balance, totalCredited, totalDebited, isLowBalance: balance < 50 }`.
    - `deductWalletFee(docType: string, cardIdentifier: string, description?: string, isManual?: boolean)`:
      - Validates session.
      - Calls `getRequiredServiceFee`. If `fee === 0`, returns `{ success: true, fee: 0, isFreeReprint: true, balanceAfter: currentBalance }`.
      - Performs atomic conditional update:
        ```typescript
        const wallet = await Wallet.findOneAndUpdate(
          { userId: user._id, balance: { $gte: fee } },
          {
            $inc: { balance: -fee, totalDebited: fee },
            $push: {
              transactions: {
                amount: fee,
                type: 'debit',
                docType,
                referenceId: cardIdentifier,
                description: description || `${docType} Card Verification Fee`,
                balanceAfter: 0, // updated with post-balance
                createdAt: new Date(),
              }
            }
          },
          { new: true }
        );
        ```
      - Fixes the `balanceAfter` of the pushed transaction to match `wallet.balance`.
      - If query matches 0 documents, fetches current balance and returns `{ success: false, error: 'INSUFFICIENT_BALANCE', requiredFee: fee, currentBalance }`.
    - `rechargeWallet(amount: number, method: 'SANDBOX' | 'UPI_QR', utrNumber?: string)`:
      - Validates amount (`amount >= 10`).
      - Performs atomic credit:
        ```typescript
        const wallet = await Wallet.findOneAndUpdate(
          { userId: user._id },
          {
            $inc: { balance: amount, totalCredited: amount },
            $push: {
              transactions: {
                amount,
                type: 'credit',
                docType: 'TOPUP',
                referenceId: utrNumber || `TOPUP-${Date.now()}`,
                description: method === 'SANDBOX' ? 'Instant Wallet Top-up (Sandbox)' : `UPI Top-up (UTR: ${utrNumber})`,
                balanceAfter: 0,
                createdAt: new Date(),
              }
            }
          },
          { new: true, upsert: true }
        );
        ```
      - Returns `{ success: true, newBalance: wallet.balance }`.
    - `getWalletTransactions(page = 1, limit = 20, filter?: 'all' | 'credit' | 'debit')`:
      - Returns paginated transactions sorted in reverse chronological order (`createdAt: -1`).
  </action>
  <verify>Ensure `src/actions/wallet.ts` compiles cleanly and executes atomic conditional queries.</verify>
</task>
