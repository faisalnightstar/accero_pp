## 2. Cross-Phase Integration Verification

1. **Authentication & Session (Phase 1) → All Protected Modules (Phases 3, 4, 5)**:
   - Next.js middleware guards `/studio`, `/dashboard`, and `/wallet`.
   - Server actions verify user sessions before database mutations or wallet deductions.
2. **Card Canvas Engine (Phase 2) → Studio Interactive Editor (Phase 3)**:
   - Studio embeds `Cr80CardContainer` and reactive canvases for all 5 document types.
   - Dynamic zoom (100%, 150%, 200%) and flip/both viewing modes operate seamlessly.
3. **Verification Gateways (Phase 4) → Missing-Field Flags (Phase 3)**:
   - Verified API payloads populate card fields.
   - Incomplete or null attributes trigger amber missing-field callouts for immediate correction.
4. **Studio Generation (Phase 3) → Wallet Ledger & Deductions (Phase 5)**:
   - Document creation executes atomic wallet deduction matching service fee schedule (₹50 PAN, ₹35 RC, ₹30 DL, ₹25 Aadhaar, ₹20 Voter, ₹5 Manual).
   - Re-printing saved documents charges ₹0 (100% free lifetime re-prints).
5. **SEO & Regional Landing Pages (Phase 6) → Interactive Studio (Phase 3/4)**:
   - 1-Click number lookup on public landing pages routes directly into `/studio?type=${type}&lookup=${id}`.
   - Dynamic metadata and schemas reflect exact document types and regional RTO zones.
