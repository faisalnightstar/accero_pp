## 1. Executive Architecture Overview

To achieve dominant organic search visibility in India's document printing ecosystem without creating low-value or cannibalizing URLs, Accero PrintPortal organizes all content into **4 mutually exclusive, collectively exhaustive (MECE) authority pillars**.

Each pillar functions as an autonomous topical cluster with a designated **Tier 1 Cornerstone Hub**, supported by **Tier 2 Commercial Services/Personas**, **Tier 3 In-Depth Technical Guides**, and **Tier 4 Comparative Pages**.

```
                           ┌────────────────────────────────────────┐

                           │               (Brand & Core SaaS)      │
                           └───────────────────┬────────────────────┘
                                               │
         ┌─────────────────────┬───────────────┴───────────────┬─────────────────────┐
         ▼                     ▼                               ▼                     ▼

   │ PILLAR A  │         │ PILLAR B  │                   │ PILLAR C  │         │ PILLAR D  │
```

## 2. Pillar A: Document Printing & Processing

### Objective
Capture high-volume transactional and commercial intent for individual government and civil document printing workflows in India.

### Structural Hierarchy
1. **Tier 1 (Pillar Hub):**
   - URL: [`/services`](https://printportal.accero.app/services)
   - Canonical Role: Central directory of supported document formatting workflows.
   - Core Value: 4-stage operator workflow pipeline, batch queue overview, card specification matrix.
2. **Tier 2 (Commercial Service Pages):**
   - [`/services/pan-card-printing`](https://printportal.accero.app/services/pan-card-printing): NSDL & UTIITSL instant lookup, automated photo & signature cropping, CR80 layout.
   - [`/services/aadhaar-document-management`](https://printportal.accero.app/services/aadhaar-document-management): UIDAI e-Aadhaar PDF masking, front/back PVC card alignment, zero-storage DPDPA compliance.
   - [`/services/voter-id-printing`](https://printportal.accero.app/services/voter-id-printing): ECI NVSP / VHA Voter ID (EPIC) formatting, bilingual Devanagari rendering, QR code embedding.
   - [`/services/driving-licence-printing`](https://printportal.accero.app/services/driving-licence-printing): MoRTH Parivahan Sarathi DL formatting, chip layout placement, class of vehicle badges.
   - [`/services/vehicle-rc-printing`](https://printportal.accero.app/services/vehicle-rc-printing): Vahan vehicle registration certificate, chassis/engine number highlight, microchip alignment.
   - [`/services/ration-card-printing`](https://printportal.accero.app/services/ration-card-printing): NFSA state food department card formatting, head of family details.
   - [`/services/farmer-id-printing`](https://printportal.accero.app/services/farmer-id-printing): AgriStack digital farmer registry card formatting, Khata/Khasra parcel records.
3. **Tier 3 (Supporting Technical Walkthroughs):**
   - [`/blog/how-to-fix-missing-card-fields`](https://printportal.accero.app/blog/how-to-fix-missing-card-fields): Practical troubleshooting when external government APIs return incomplete records.
4. **Internal Linking Rules:**
   - Every service page must link to `/services` (breadcrumb), `/pricing` (fee transparency), and the corresponding hardware guide in Pillar C.

## 4. Pillar C: PVC Card Printing & Hardware Calibration

### Objective
Capture informational and technical troubleshooting intent from operators struggling with desktop printer alignment, driver settings, tray feeding, and card dimensions.

### Structural Hierarchy
1. **Tier 1 (Pillar Hub):**
   - URL: [`/pvc-card-printing-software`](https://printportal.accero.app/pvc-card-printing-software)
   - Canonical Role: Technical overview of browser-native PVC card printing engine without third-party desktop drivers.
2. **Tier 2 (Technical Resource Directory):**
   - URL: [`/resources`](https://printportal.accero.app/resources)
   - Canonical Role: Downloadable cheat-sheets, CSS `@media print` rules, DPI converters, and printer tray matrices.
3. **Tier 3 (Authoritative Cornerstone Guides):**
   - [`/blog/cr80-card-dimensions-guide`](https://printportal.accero.app/blog/cr80-card-dimensions-guide): Definitive guide on ISO/IEC 7810 ID-1 standard dimensions ($85.60\text{ mm} \times 53.98\text{ mm}$, corner radius $3.18\text{ mm}$, 300 vs 600 DPI pixel math).
   - [`/blog/pvc-card-printer-tray-guide`](https://printportal.accero.app/blog/pvc-card-printer-tray-guide): Step-by-step setup for Epson L805/L8050/L18050 CD/DVD trays and Canon G570/G670 Type M trays.
   - [`/blog/multilingual-document-printing-guide`](https://printportal.accero.app/blog/multilingual-document-printing-guide): Devanagari script font rendering, ligature handling, and bilingual layout alignment.
4. **Internal Linking Rules:**
   - Cornerstone guides act as authoritative link targets. Every service page linking to hardware advice points to `/blog/pvc-card-printer-tray-guide`. Every page referencing physical dimensions links to `/blog/cr80-card-dimensions-guide`.
